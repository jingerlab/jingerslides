# jingerslides
A browser-based, component-driven 3D presentation studio that transforms slides into interactive, multi-axis spatial web experiences with zero-dependency single-file HTML exports.
## Repository Overview
SpatialDeck Component Studio is an open-source, client-side presentation authoring tool designed for non-linear, spatial storytelling. Rather than relying on traditional linear slides, SpatialDeck allows creators to position presentation frames across a 3D coordinate canvas (+X, -X, +Y, -Y, and Z-depth stacking).  3D Spatial Branching: Layout slides along 2D coordinate grids or stack them along the Z-axis for seamless zoom transitions.  Modular Slide Components: Build slides dynamically using pre-built elements including text blocks, media embeds (videos, images, iframes), stat metric orbs, interactive MCQ quizzes, custom buttons, and raw HTML/SVG blocks.  Single-File Portable Export: Export full presentation decks into a standalone, zero-dependency index.html document with 60 FPS GPU-accelerated CSS 3D transforms.  Interactive HUD & Minimap: Navigational waypoint HUD featuring real-time node tracking, customizable avatar beacons, connected branch lines, and floating edge navigation controls.  Local Persistence: Authors and edits decks entirely in the browser with automatic localStorage draft autosaving
